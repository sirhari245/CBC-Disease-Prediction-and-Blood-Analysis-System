# CBC-Disease-Prediction-Aand-Blood-Analysis-System:
# Purpose of the Project:
The main purpose of this project is to develop a simple and efficient healthcare web application that can analyze Complete Blood Count (CBC) values 
identify possible abnormal blood conditions based on standard medical ranges. The system is designed to help users digitally enter blood parameters such as Hemoglobin, WBC, RBC, and Platelet counts 
instantly receive basic health analysis results.
